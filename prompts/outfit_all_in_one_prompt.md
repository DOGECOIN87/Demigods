The prompt makes the assistant download the right base pose from this public repository, pinned to commit `5c44513a564a`, and verify its SHA-256. It then renders, checks the result against a checklist and retries up to twice, and returns the file name and a `sources.json` entry for intake.

If the assistant cannot use a downloaded file as its edit input, the prompt makes it stop and ask you to attach the named file instead of guessing. Attach it, and the run continues.
