# Demigods outfit prompt pack (2026-10-11)

Generated by `python scripts/build_outfit_prompt_pack.py`. Do not edit by hand: change the script and rerun it. Background and pose notes are in `docs/pose_anatomy_2026-10-11.md`.

## How to use

1. **Attach one image only**: the base pose named in the prompt, from `assets/base_bodies/`. It is the sole reference.
2. Paste the whole prompt. Generate **Pose 001 first** for a family and review it. Then run Poses 002-005 with the same outfit text so the design stays identical.
3. Keep the original PNG unedited. Save it to `images/trait_candidates/outfits_dressed/` and add a `sources.json` entry whose `target` is the output name in the prompt.
4. Run `python scripts/intake_dressed_bodies.py images/trait_candidates/outfits_dressed/sources.json` and review the sheets (`docs/workflows/dressed_body_intake.md`).

Checklist before accepting a render:

- the head is bald and faceless, and the same size and place as the base;
- the hands are bare skin and unmoved, and the Pose 002/003 fist is clear of fabric;
- in Pose 004 the image-left forearm is bare from the elbow down;
- no tank top or shorts show anywhere;
- the background is transparent (or flat black for the outfits that allow it).
