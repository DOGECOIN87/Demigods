# Legendary variations

Twelve outfit-and-setting variations on each of six registered legendaries, 72 in all, planned in [`prompts/legendary_variation_pack_2026-09-25.md`](../../prompts/legendary_variation_pack_2026-09-25.md). Each keeps its legendary's face, hair, eyes and pose and redesigns the costume and setting.

**Received: 4 of 72.** The prompt pack's own status lines date from before generation. This page is the live status.

Variations are not 1-of-1 characters and are not counted in the 77 in [`../one_of_ones/`](../one_of_ones/README.md).
