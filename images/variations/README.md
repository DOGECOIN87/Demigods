# Demigods variations

The [completed 72-image collection](complete_72/README.md) contains the current named PNG set, numbered 001–072, all 1254 × 1254. It supersedes the earlier six-family prompt plan and its incomplete status table.

48 byte-identical older copies were removed from `images/one_of_ones/` after comparison against the new images' Git blob hashes. The historical roster there links to their new names.

`nature/` contains four older 1024 × 1024 WebP variations pending an owner cleanup decision. `references/` and `sources.json` preserve earlier source provenance. These older files are excluded from the current 72-image set.

## Transparent cutouts (2026-10-09)

[`cutouts_2026-10-09/`](cutouts_2026-10-09/README.md) holds all 77 rare 1-of-1 images with the background removed: the 72 PNGs in `complete_72/`, the four `nature/` WebPs and the JPEG in `references/`. Each was cut out individually; its notes and corrections are in `cutouts_2026-10-09/recipes/`. The earlier blur/depth-treated review set and its background counterpart were removed.
