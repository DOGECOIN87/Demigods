## Operator loop

1. Paste one prompt into the image model with the listed attachments.
2. Save the returned PNG into `incoming/` under its canonical filename.
3. When the batch is done, run `python scripts/bulk_intake.py incoming/` to QA everything and render a single review sheet.
4. Approve on the sheet, then register with `python scripts/bulk_intake.py incoming/ --register-approved <ids>`.
